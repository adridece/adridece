### Featured project

**[Cerezium Autopilot](https://github.com/adridece/cerezium-autopilot)**: a Chrome extension that batch-produces
YouTube Shorts with Google Flow's AI agent. It generates every scene image, animates each one and saves the numbered
clips automatically, across two accounts in parallel and in background tabs.

- Keeps background tabs working through tab capture and the Chrome DevTools Protocol
- Saves files without dialogs through the File System Access API
- Detects failures by counting results, so a clip is never paid for twice
- Covered by unit tests and a 34-scenario end-to-end suite against a simulated version of the target app
