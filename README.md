### 🚀 Featured project

**[Cerezium Autopilot](https://github.com/adridece/cerezium-autopilot)**: a Chrome extension (Manifest V3) that
batch-produces YouTube Shorts with Google Flow's AI agent. It generates every scene image, animates each one,
and saves the numbered clips automatically, across two accounts in parallel and in background tabs.

- Keeps background tabs alive with `tabCapture` and drives focus-gated input through the Chrome DevTools Protocol
- Saves files without dialogs via an offscreen document and the File System Access API
- Detects failures by counting results, so a clip is never paid for twice
- Tested with unit tests and a 34-scenario end-to-end suite against a simulated version of the target app
